How I work

My process

Every project follows the same four steps: understand the question, clean the data, model or analyze it, and communicate the result. I spend most of my time on the first two, because a model is only as good as the data behind it.

I prefer simple, explainable tools when they work, and I document each step so others can reproduce and extend it.

1. Understand
2. Clean
3. Model
4. Communicate
